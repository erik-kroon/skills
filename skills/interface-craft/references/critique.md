# Critique Mode

Use critique mode to evaluate whether an interface works as a designed
experience.

## Check

- AI-slop tells: generic gradients, glassmorphism, repeated card grids, gradient text, glow-heavy dark UI, generic fonts.
- Visual hierarchy: can the user find the primary action in two seconds?
- Information architecture: are related things grouped and ordered well?
- Emotional fit: does it feel trustworthy, calm, premium, playful, or utilitarian as appropriate?
- Affordance: are interactive elements obviously interactive?
- Composition: does spacing feel intentional or accidental?
- Typography: does type communicate reading order?
- Color: does color communicate state and emphasis?
- States: are empty/loading/error/success states helpful?
- Microcopy: are labels and errors clear?

## Output

- `Anti-pattern verdict`
- `Overall impression`
- `What works`
- `Priority issues`
- `Minor observations`
- `Questions to consider`
