# Type Mode

Use type mode to improve typography, readability, font choices, and text
hierarchy.

## Assess

- Is the reading order obvious?
- Are headings, body, labels, and metadata clearly distinct?
- Are lines too long, too short, or too dense?
- Does the type choice match the surface register?
- Are numeric values, tables, and code-like content easy to scan?
- Do weights and sizes form a real hierarchy?
- Does text wrap gracefully at narrow widths?

## Moves

- Set readable line length for prose.
- Use scale and weight together rather than tiny size tweaks.
- Choose typefaces for voice and utility, not default availability.
- Use tabular numbers for aligned metrics and tables.
- Tighten labels and metadata without damaging legibility.
- Avoid overusing uppercase and letter spacing.
- Verify real content, long content, and translated content.

## Output

- `Typography issue`
- `Type changes`
- `Readability impact`
- `Verification`
