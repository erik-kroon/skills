# Distill Mode

Use distill mode to remove unnecessary complexity.

## Check

- Duplicate content.
- Too many actions at once.
- Excessive cards, panels, and containers.
- Decorative elements that do not support comprehension.
- Redundant headings and helper text.
- Competing primary actions.
- Nested flows that can be flattened.

## Principles

- Keep the user's main job visible.
- Remove before restyling.
- Preserve necessary hierarchy.
- Make the simplest version feel intentional, not empty.

## Output

- `Removed complexity`
- `Preserved essentials`
- `Simplified flow`
- `Risks`
