# Simplify Mode

Use simplify mode to remove unnecessary complexity.

## Check

- Duplicate content or repeated explanations.
- Too many actions visible at once.
- Excessive cards, panels, dividers, tabs, and containers.
- Decorative elements that do not improve comprehension.
- Redundant headings, helper text, and labels.
- Competing primary actions.
- Flows that can be flattened or made progressive.
- Code paths, variants, and props that exist only to support visual noise.

## Method

1. Name the user's main job.
2. Mark each element as essential, contextual, optional, or removable.
3. Remove before restyling.
4. Rebuild hierarchy from the remaining essentials.
5. Preserve affordance and state clarity.

## Output

- `Removed complexity`
- `Preserved essentials`
- `Simplified flow`
- `Risks`
