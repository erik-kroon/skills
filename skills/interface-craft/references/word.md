# Word Mode

Use word mode to improve UX writing and comprehension.

## Check

- Button labels name the action, not the component.
- Empty states explain what will appear, why it matters, and how to start.
- Error messages name the problem, cause when useful, and recovery path.
- Form labels are concrete and domain-consistent.
- Help text appears where decisions are made.
- Success messages confirm the outcome and next safe action.
- Loading text sets expectation only when waiting is meaningful.
- Confirmation copy states consequence, especially for destructive actions.
- Navigation labels match the user's mental model.

## Principles

- Prefer specific verbs and nouns.
- Remove copy that repeats visible UI.
- Keep error copy non-blaming.
- Use domain language when it helps, plain language when it clarifies.
- Make irreversible actions explicit.

## Output

- `Copy issues`
- `Before/After/Why table`
- `Terminology decisions`
- `Unresolved wording questions`
