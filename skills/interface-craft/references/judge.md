# Judge Mode

Use judge mode to decide whether an interface works as an experience.

## Lenses

- Job clarity: can the user tell what this surface is for?
- Hierarchy: can the primary action or primary information be found quickly?
- Information architecture: are related decisions grouped and ordered well?
- Cognitive load: is the user forced to remember, compare, or hunt too much?
- Emotional fit: does the surface feel right for the audience and moment?
- Affordance: are interactive elements visibly interactive?
- Trust: does the interface make state, cost, risk, and consequence clear?
- Accessibility: can keyboard, screen reader, low-vision, and reduced-motion
  users complete the task?
- Distinctiveness: does the design avoid obvious generated-design tropes?

## Persona Passes

Run at least two relevant passes when the surface is important:

- Impatient expert: wants speed, density, and keyboard efficiency.
- First-time user: needs orientation and clear next steps.
- Accessibility-dependent user: needs robust semantics, contrast, and focus.
- Distracted mobile user: needs priority, thumb-safe actions, and resilience.
- Stress tester: tries long text, empty data, errors, and edge states.

## Scoring

If the user asks for a review score, score each lens from `1` to `5` and explain
only the weak scores. Avoid false precision.

## Output

- `Overall verdict`
- `What works`
- `Priority issues`
- `Persona risks`
- `Recommended next mode`
