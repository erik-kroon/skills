# Clarify Mode

Use clarify mode to improve UX writing and comprehension.

## Check

- Button labels are action-specific.
- Empty states explain what happened and what to do next.
- Error messages name the problem and recovery path.
- Form labels are concrete and consistent.
- Help text appears where decisions are made.
- Terminology matches the product domain.
- Copy is not repeating visible UI.
- Tone matches the product context.

## Principles

- Prefer verbs for actions.
- Prefer specific nouns over generic labels.
- Remove instructions the interface can make obvious.
- Keep error copy non-blaming.
- Make destructive actions explicit.

## Output

- `Copy issues`
- `Before/After/Why table`
- `Terminology decisions`
- `Unresolved wording questions`
