# Polish Mode

Use polish mode only when the interface is functionally close to done.

## Check

- Alignment and spacing.
- Typography hierarchy, line length, line height.
- Color and contrast.
- Complete interaction states.
- Smooth, purposeful transitions.
- Copy consistency.
- Icon sizing and optical alignment.
- Form labels and validation.
- Loading, empty, error, and success states.
- Responsive behavior.
- Performance and layout shift.
- Debug logs, dead comments, unused imports.

## Checklist

- [ ] Alignment works at all breakpoints.
- [ ] Spacing uses tokens or consistent scale.
- [ ] Type hierarchy is consistent.
- [ ] Interactive states are complete.
- [ ] Touch targets are large enough.
- [ ] Contrast meets WCAG AA where applicable.
- [ ] Keyboard navigation works.
- [ ] No layout shift or text overflow.
- [ ] Reduced motion is respected.
- [ ] Code is clean.

## Output

- `Polish changes`
- `Before/After/Why table`
- `Verification`
- `Remaining polish`
