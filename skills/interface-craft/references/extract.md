# Extract Mode

Use extract mode to turn repeated interface decisions into reusable system
assets.

## Look For

- Repeated component structures.
- Repeated spacing or color decisions.
- Repeated empty/error/loading states.
- Repeated motion patterns.
- Inconsistent variants that should be one component.
- Local primitives that belong in the design system.

## Workflow

1. Discover repeated patterns.
2. Choose what should become reusable.
3. Define the API or token.
4. Migrate the smallest useful set of call sites.
5. Document intended use.

## Output

- `Candidates`
- `Extraction plan`
- `New or changed system assets`
- `Migrated usage`
- `Follow-up candidates`
