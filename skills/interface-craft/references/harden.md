# Harden Mode

Use harden mode to make an interface robust in real conditions.

## Check

- Long names, long words, and translated text.
- Empty data and partial data.
- Loading states and skeletons.
- Error states and retry paths.
- Offline or slow-network behavior when relevant.
- Permission-denied states.
- Disabled and pending states.
- Time zones, numbers, dates, and locale formatting.
- Focus management after async changes.
- Layout stability with images and dynamic content.

## Output

- `Edge cases covered`
- `State gaps fixed`
- `I18n/locale issues`
- `Verification`
- `Remaining hardening risks`
