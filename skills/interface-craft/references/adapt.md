# Adapt Mode

Use adapt mode when the same design must work in a different context.

## Contexts

- Mobile, tablet, desktop, wide desktop.
- Touch, mouse, keyboard.
- Print or email.
- Slow network or offline use.
- Dense operational use versus occasional use.

## Principles

- Adapt, do not merely shrink.
- Keep critical functionality available.
- Replace hover-only behavior on touch.
- Use touch targets large enough for fingers.
- Reflow information by priority.
- Use container queries when component context matters.
- Test narrow and wide layouts.

## Output

- `Source context`
- `Target context`
- `Adaptation strategy`
- `Changes`
- `Verification`
