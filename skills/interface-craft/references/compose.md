# Compose Mode

Use compose mode to improve layout, spacing, visual rhythm, and hierarchy.

## Assess

- Is the primary area obvious?
- Are related controls and content grouped?
- Does the layout use space to express importance?
- Is density appropriate for repeated use?
- Are there too many boxes, borders, cards, or containers?
- Does the rhythm change between sections or feel mechanically even?
- Do narrow and wide layouts preserve the same priority?

## Moves

- Establish a spacing scale or follow the existing one.
- Use alignment before adding decoration.
- Vary section rhythm intentionally.
- Replace monotonous grids with priority-based composition.
- Use elevation only when it communicates layering or interaction.
- Make optical adjustments for icons, badges, inputs, and dense controls.
- Prefer container-aware layout over viewport-only assumptions when possible.

## Output

- `Layout issue`
- `Composition changes`
- `Hierarchy impact`
- `Responsive verification`
